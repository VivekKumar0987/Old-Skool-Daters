# Image guide

- `docs/images/branding/`: logo
- `docs/images/concepts/`: generated design explorations; all people and data are illustrative
- `docs/images/focus/`: cropped emphasis views of concept modals (linked to their full images)
- `docs/images/prototype/`: actual local prototype captures, converted to WebP to reduce file size
- `docs/images/extras/`: earlier concept alternatives in an expandable gallery
- `docs/images/how-it-works.svg`: four-step product flow
- `docs/images/availability.svg`: conceptual online/offline explanation

GitHub renders the pictures inline when their files are committed in these exact paths. JavaScript interactions are not supported in GitHub README; the experience uses clickable anchor links, image enlargement and expandable details.

Extract files into the **repository root** (where README.md lives), then commit and push.
